DAW import guide

Works with every major DAW that accepts standard .mid files.
Ableton Live
Drag the .mid file into the Arrangement or Session view. Assign a software instrument to the new MIDI track.
FL Studio
Open the Piano Roll → File → Import MIDI, or drag the .mid directly into the Playlist.
Logic Pro
Drag .mid into the Tracks area. Logic auto-creates a Software Instrument track.
Pro Tools
File → Import → MIDI. Create a new MIDI track and assign your instrument plugin.
GarageBand
Drag .mid files into the Tracks area. GarageBand assigns a default instrument automatically.
Reaper
File → Import → MIDI File, or drag directly into the timeline. Assign VSTi as needed.
